# KFUPM Circle
**SWE363 · Section 01 · Team 7**

KFUPM Circle helps KFUPM students discover classmates who share their courses and interests, connect with other students, join clubs, and find companions for activities.

## Phase 4: Front-End Development

This phase focuses on implementing an interactive React front end based on our Figma prototype. The interface will support both desktop and mobile screens.

## Figma Prototype

[View our Figma prototype](https://swe363-sec1-team7.figma.site)

## Main Features

- Account registration and sign-in
- Student profiles and discovery
- Connections and messaging
- Clubs, activities, and invitations
- Club management
- Administration and report management

## Getting Started

### Prerequisites

Make sure Node.js and npm are installed on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/baderbbh/kfupm-circle.git
   ```

2. Open the front-end folder:

   ```bash
   cd kfupm-circle/frontend
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal to view the website.

### Available Commands

Run these commands from the `frontend` folder:

| Command | Description |
|---------|-------------|
| `npm run dev` | Start the local development server. |
| `npm run build` | Create a production build. |
| `npm run preview` | Preview the production build after running `npm run build`. |
| `npm run lint` | Check the code for issues using ESLint. |
